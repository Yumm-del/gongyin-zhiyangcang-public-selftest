# 许可控制虚构样本

`permission-cases.csv`逐笔对应[风险控制矩阵](../../models/养老金咨询案例-风险控制矩阵-v1.xlsx)的“许可测试底稿”S01至S08，沿用同日分钟数、案例编号和执行状态。客户编号均为虚构；没有真实客户信息。

演示假定入队前已有有效同渠道许可。空撤回时间表示演示记录无撤回，不表示已经独立验证许可。空发送时间与“已发送”并存属于证据缺失；“已取消”还需真实取消回执支持。

同分钟发送与撤回采用“撤回已生效”的保守教学口径。真实测试需要事件顺序、一致时钟及渠道提交边界，不能用分钟粒度直接确定真实违规。

预期输出：8条记录，其中3条`CONTROL_FAILURE`、1条`EVIDENCE_GAP`、2条`CANCELLED_NOT_SENT`、2条`NO_EXCEPTION_IN_DEMO`。这些是人为植入缺陷的复算，不能认定为Alpha原型或银行缺陷。
